# Masters Dissertation Artefact

Standalone research prototype for the UWE Data Science MSc dissertation: 
does probabilistic, data-driven theatre session packing (using individualised 
case duration predictions) achieve higher utilisation/throughput than 
traditional case-mix heuristics, evaluated by simulation on a synthetic 
Trauma & Orthopaedics waiting list.
